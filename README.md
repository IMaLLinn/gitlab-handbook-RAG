# gitlab-handbook-rag

用 GitLab 的公开公司手册做的一个知识库问答 RAG，顺带把评测认真做一遍。

## 背景

公司内部手册这种东西，内容全，但没人愿意翻。请假、报销、入职流程这些问题每天都有人问，答案其实都在手册里。这个项目就是把手册做成能直接问的问答系统：问什么，它去手册里找依据再回答；手册里没有的，要明确说查不到，不能瞎编。

语料用 GitLab 的公司手册，因为它是真公司在用的，2000 多页，公开能拿到，许可 是 CC BY-SA 4.0，引用的时候会注明出处。先不贪多，挑 50 到 100 页结构清楚的做扎实了再说。

评测集自己标，每道题都对应到手册的具体页面，对不对能回去核对。题分几种：一个页面就能答的、要跨几个页面拼的、带条件的（比如分岗位和地区），还有手册里根本没有的，这种就看它会不会老实拒答。

要看的就几件事：该找的页面找没找回来、回答对不对、有没有依据、该拒答的时候拒没拒。再就是参数怎么选，chunk 切多大、top-k 取几，改完之后同一套题重跑，看数字到底有没有变好。失败也要分清是检索没找到、找到了没用上，还是它自己编的，三种毛病改法不一样。

跟 LLM-Eval-Lab 的关系：那边是评测和选型的方法，这个是拿来练手的真应用。

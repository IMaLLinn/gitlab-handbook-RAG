# GitLab Handbook RAG

基于 GitLab 公开的公司手册，构建一个支持来源引用的知识库问答系统，并通过检索和回答质量评测，研究不同 RAG 策略对问答效果的影响。

## 项目介绍

项目以 GitLab Handbook 为知识来源，选取其中的公司制度、工程流程和日常工作文档，搭建文档处理、文本切分、向量检索和大模型生成的完整流程。

系统的目标不只是生成回答，还需要找到相关文档、提供可核对的引用，并在缺少可靠依据时拒绝回答，减少模型编造信息的情况。

## 评测与优化

项目计划建立一套人工标注的问答测试集，每道题对应具体的原始文档，覆盖单页事实查询、跨文档综合、条件判断和无答案问题。

评测重点包括：

* 检索质量：相关文档能否被正确召回。
* 回答质量：答案是否准确，是否有原文依据。
* 拒答能力：遇到文档无法回答的问题，能否避免编造。
* 参数对比：比较不同文本切分大小、检索数量（top-k）对结果的影响。

根据测试结果区分检索失败、信息利用不足和无依据生成等问题，针对主要错误进行调整，再使用同一套测试集验证改进效果。

## 与 LLM-Eval-Lab 的关系

LLM-Eval-Lab 侧重大模型的独立评测、模型选型和自动化回归测试。本项目则关注 RAG 应用中的检索效果、回答可靠性和参数优化。

两个项目分别展示模型评测与实际应用优化方面的能力。
